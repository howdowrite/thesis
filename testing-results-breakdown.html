What Is This Experiment? Primary

You're testing a Delegation Advisor — a system that tries to predict whether a cheaper AI model (Kimi) can solve a coding task, so it can route easy tasks to the cheap model and hard tasks to the expensive "frontier" model.

Goal: Save money without losing many solved tasks.

Dataset: 266 tasks from 3 Python projects (ansible, openlibrary, qutebrowser), each run once with a 50-call cap.

Baseline policy (Policy C — "Cheaper First"): Try the cheap model first; if it fails, fall back to the frontier model.

Model & Training Procedure

  • Model: Logistic regression (L2 regularization) with StandardScaler on the 7 features.
  • Label: out_kimi_solved (1 if Kimi solves the task, 0 otherwise).
  • Regularization (C): Chosen by inner 5-fold CV on training folds minimizing mean log loss (not accuracy). Candidate values: {0.01, 0.1, 1.0, 10.0}. Ties → smaller C.
  • Outer CV: 20 repetitions × stratified 5-fold (seed 42). Each task gets 20 out-of-fold probability estimates; final prediction = mean across reps.
  • Routing threshold (θ): Per training fold, θ = mean Kimi cost / mean Opus cost on that fold (~0.14). Task routed to frontier if predicted probability < θ.

AUC Calculation

  • Primary AUC: Out-of-fold predictions averaged over 20 reps vs. true Kimi success labels. Computed via sklearn.metrics.roc_auc_score.
  • DeLong test: Correlated AUC comparison on same tasks (used for T3, T4). Implemented in advisor_common.delong().
  • Brier score: Mean squared error of predicted probabilities vs. binary outcomes. Lower = better calibrated.

Leave-One-Repository-Out (LORO)

Train on 2 repositories, predict the 3rd. No mixing. Each task gets exactly one prediction from a model that never saw its repository.

  • Primary Advisor LORO AUC: 0.540 (95% CI: 0.463–0.615)
  • Embedding Advisor LORO AUC: 0.497 (worse than chance)
  • Hold-flag LORO AUC: 0.540 (pooled), per-repo: ansible 0.535, openlibrary 0.646, qutebrowser 0.528

Bootstrap Confidence Intervals

10,000 paired bootstrap resamples (seed 42). For each resample, tasks are sampled with replacement and all metrics recomputed. 95% CI = 2.5th and 97.5th percentiles.

Leakage Checks

  • Shuffled-label check (default mode): Labels permuted before training AND scoring. AUC should be ~0.5. Passes if mean AUC over 5 permutations is within 0.06 of 0.5.
  • Frozen data hashes: Scripts refuse to run if input CSV SHA-256 differs from protocol-recorded values.
  • No post-hoc feature selection: Screening threshold (10%) and kept features are frozen in protocol before first real run.

One-Sentence Summary

The Delegation Advisor doesn't save money over the trivial "try cheap model first" strategy, its predictive signal doesn't transfer to new repositories, and the primary claim is formally not supported — though it does rank tasks better than random and better than a repository-only baseline.
